# 文字转语音

TTS 由框架原生 Rust 插件 `tts` 提供，RedLang 通过同名服务调用。启用管理台中的 TTS 插件后，即可在脚本中合成语音、查询在线人声及查看参考样本，无需安装 Python 或额外的 Python 依赖。

## 生成与发送语音

最简单的调用：

```text
【语音@【TTS@你好，欢迎使用文字转语音。】】
```

`【TTS】` 返回音频字节集，`【语音】` 将它转换为当前会话的语音消息内容。TTS 插件只返回合成结果，不自行调用适配器发送消息。

指定中文别名或完整人声 ID：

```text
【语音@【TTS@今天为你带来游戏资讯。@晓晓】】
```

```text
【语音@【TTS@今天为你带来游戏资讯。@zh-CN-YunxiNeural】】
```

原有的 `【TTS@文本@音色】` 用法继续可用；省略或留空音色时，仍使用 `YunyangNeural`（云扬）。

完整 ID 优先精确匹配。旧式音色名片段在只匹配一个人声时继续有效；如果匹配到多个人声，会提示填写完整 ID。指定的人声不可用时会报错，避免生成与所选音色不符的语音。

## 参数设置

完整格式：

```text
【TTS@文本@音色@语速@音调@音量@总超时秒@额外重试次数】
```

除文本外，其余参数均可省略或留空，使用默认值。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 文本 | 无 | 要朗读的内容 |
| 音色 | `YunyangNeural` | 完整人声 ID、兼容的音色名或中文别名 |
| 语速 | `0` | 相对默认语速的百分比变化，`-99～1000`，支持整数或 `%` 后缀 |
| 音调 | `0` | 相对音调变化，`-1000～1000 Hz`，支持整数或 `Hz` 后缀 |
| 音量 | `0` | 相对默认音量的百分比变化，`-100～100`，支持整数或 `%` 后缀 |
| 总超时秒 | `12` | `1～120` 秒，一次合成操作的总时限，包含网络请求和重试 |
| 额外重试次数 | `1` | `0～3` 次，网络失败后允许再尝试的次数，仍受总时限约束 |

语速提高 20%、音调降低 5 Hz、音量保持默认：

```text
【语音@【TTS@这是一段语音参数演示。@云希@+20%@-5Hz@0%】】
```

也可以只填整数：

```text
【语音@【TTS@这是一段稍慢的语音。@晓晓@-15@0@-10@20@1】】
```

其中 `-15` 表示语速相对降低 15%，`-10` 表示音量相对降低 10%。它们不是每分钟字数或绝对音量。音调调整只改变音高，选择不同说话人应使用音色参数。

总超时设置为 20 秒、关闭额外重试，其他参数使用默认值：

```text
【语音@【TTS@你好。@@@@@20@0】】
```

表中的范围是本插件的输入边界，不代表在线服务保证所有极端值都能达到预期听感，建议先小幅调整。接口只接受规定格式的整数参数，错误格式及越界参数会报错，不会作为文本或 SSML 片段直接交给服务。自定义情绪、任意 SSML 和声音克隆不属于此命令的能力。

## 查询全部在线人声

```text
【TTS人声@语言前缀@性别@总超时秒】
```

此命令返回在线服务目录的对象数组。为减少重复请求，同一代理设置下的人声目录缓存最多 5 分钟；缓存失效后重新联网查询。语言留空或为 `all` 时返回全部语言；性别留空时不筛选，可填写 `Male`、`Female`、`男` 或 `女`。总超时默认 12 秒，允许 `1～120` 秒。

| 调用 | 结果 |
| --- | --- |
| `【TTS人声】` | 全部在线人声 |
| `【TTS人声@all】` | 全部在线人声 |
| `【TTS人声@zh】` | 语言代码以 `zh` 开头的人声 |
| `【TTS人声@zh-CN@女】` | 中国大陆中文女声，包含匹配该前缀的地区项 |
| `【TTS人声@en-US@Male@20】` | 美国英语男声，查询总时限 20 秒 |

每个对象包含：

| 字段 | 含义 |
| --- | --- |
| `id` | 完整人声 ID，可直接用作 TTS 的音色参数 |
| `name` | 服务返回的人声名称 |
| `locale` | 语言及地区代码 |
| `gender` | 性别 |
| `aliases` | 该人声可使用的别名数组 |

将全部中文女声 ID 排成文本：

```text
【定义变量@人声列表@【TTS人声@zh@女】】
【循环@【变量@人声列表】@【函数定义@
    【取元素@【参数@2】@id】【换行】
】】
```

列表本身是数组，脚本可以继续筛选、分页或格式化，不受某个预设别名数量限制。实际可选人声以查询结果为准，在线服务会调整目录。

## 参考页的 28 条声音样本

```text
【TTS样本】
```

此命令返回随插件提供的 28 个静态样本对象，本次调用不联网，也不查询这些声音的实时可用状态。字段如下：

| 字段 | 含义 |
| --- | --- |
| `id` | 参考声音完整 ID |
| `name` | 中文名称 |
| `category` | 参考目录中的分类 |
| `gender` | 参考目录中的性别信息 |
| `sample_url` | 已有 MP3 样本的 URL |
| `source_url` | 原始参考页面 URL |

播放第一条已有样本：

```text
【定义变量@样本@【取元素@【TTS样本】@0】】
【语音@【取元素@【变量@样本】@sample_url】】
```

数组序号从 0 开始。实际播放时由原生语音命令及适配器获取音频 URL；这段脚本播放已有文件，不重新合成文字。

需要确认某个人声能否实时合成，可以直接生成一句试听：

```text
【语音@【TTS@你好，这是一段实时生成的人声试听。@晓晓】】
```

样本来自[原始声音试听页](https://jangviktor-web.github.io/novel2voice/scripts/voice_samples/index.html)。该项目的[样本生成脚本](https://github.com/jangviktor-web/novel2voice/blob/4df8583e37268fadd80759bd3c0c0f19e8977e3a/scripts/generate_voice_samples.py)使用第三方 HTTP 服务，不能将样本存在等同于当前 Edge 接口支持合成自定义文字。

2026-11-13 核对时，这 28 个声音中有 14 个列于 Edge 在线目录、14 个未列出。这个数字是一次核对记录；`【TTS样本】` 不携带或更新可用状态，当前选择应结合 `【TTS人声】` 和实际合成结果。

## 用于聊天触发脚本

TTS 命令可以放入已有的群聊或私聊脚本。例如，建立关键词为 `朗读 `（末尾有空格）的前缀匹配脚本，内容写为：

```text
【语音@【TTS@【子关键词】@晓晓】】
```

用户发送 `朗读 你好，欢迎回来。` 后，脚本将匹配到的文字交给 TTS，并返回语音消息。

这只是脚本配置示例，启用 TTS 插件本身不会自动创建聊天关键词。合成文本应通过变量或 `【子关键词】` 传入，不需要拼接成新的 RedLang 源代码。

## 代理、插件状态与错误处理

合成和在线人声查询继续使用脚本环境中的框架代理设置，与原有 TTS 调用保持一致。代理未设置时直连；设置方式沿用 RedLang 的代理命令。

如果 TTS 插件未启用，调用会明确返回“`TTS 插件未启用`”错误。可在框架管理台启用 TTS；脚本侧通过 `tts` 服务访问能力，不需要安装独立目录包。

合成依赖在线服务。超时、人声不再可用、服务暂时拒绝请求等情况会返回错误；重试不会保证服务一定可用。参数错误应先修正参数，再重新调用。

插件最多同时处理 4 个合成或人声查询请求；超过时会提示稍后重试。停用插件会清空目录缓存并拒绝后续请求，已开始的网络操作仍受本次总时限约束。

语音合成成功与平台能够发送语音是两个步骤。如果已有音频却发送失败，请检查适配器和协议端的语音能力；部分 OneBot 实现需要在协议端安装 FFmpeg。

## 实现位置

- `crates/plugin-tts`：原生 TTS 插件，注册 `tts` 服务并实现人声查询与合成。
- `crates/redreply-common`：插件间共享的服务端口。
- `crates/plugin-redlang`：注册 RedLang 命令，通过服务调用 TTS。
- `crates/msedge-tts`：底层 Edge 语音接口。
